# randoroute preview map store

Map data for testing before it goes to the live map store, for the
randoroute app's preview (Settings, Lab, "Choose the map store"). Built from open sources:
OpenStreetMap (ODbL), the US Census, the USDA Forest Service, FHWA HPMS and
the states' transportation departments' open data; see each state's
attribution in index.json. Generated by scripts/preview_store.mjs; every
publish replaces this branch with one commit.
